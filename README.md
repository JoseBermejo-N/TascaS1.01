# 🎨 HTML & CSS Layout Projects

Welcome to my web layout repository! This space is dedicated to practicing frontend fundamentals, building responsive designs, and mastering semantic HTML and modern CSS positioning using Visual Studio Code.

The main goal is to convert visual ideas into clean, structured, and visually appealing web pages.

## 🚀 Development Environment
* **Languages:** HTML5 & CSS3
* **Editor:** [Visual Studio Code](https://visualstudio.com)
* **Recommended Extension:** Live Server (to preview layouts in real-time)

## 📂 Repository Structure

The project is organized by distinct layout exercises and challenges:

* `01-semantic-structure/`: Practice with semantic tags (`<header>`, `<nav>`, `<article>`, `<footer>`).
* `02-css-selectors-box-model/`: Exercises focused on margins, padding, borders, and advanced selectors.
* `03-flexbox-layouts/`: Building flexible alignment layouts (navigation bars, card grids).
* `04-css-grid/`: Multi-column layouts and full page dashboard mockups.
* `05-responsive-design/`: Media queries practice to make layouts mobile-friendly.

## 🛠️ How to View the Projects

If you want to explore and preview these layouts in your local environment, follow these steps:

1. **Clone this repository:**
   ```bash
   git clone https://github.com/JoseBermejo-N/TascaS1.01.git
   ```

2. **Open the folder in your editor:**
   Open Visual Studio Code, go to `File -> Open Folder`, and select the cloned repository folder.

3. **Run the live preview:**
   * Install the **Live Server** extension in VS Code if you haven't already.
   * Open any `index.html` file.
   * Click the **"Go Live"** button at the bottom right corner of VS Code, or right-click inside the HTML file and select **"Open with Live Server"**.
   * A new browser tab will automatically open with the project running.
